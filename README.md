## How To Use

### For Guests

1. Open the app and sign in or create an account.
2. Go to the Home tab to view the latest salon banners and updates.
3. Tap any banner to open more details in a popup.
4. Open the Services tab to browse service categories.
5. Add one or more services to your booking list.
6. Tap **Book Selected Services** to create a booking request.
7. Go to the Messages tab to view your conversations with the admin team.
8. Open the conversation created for your booking and wait for an admin reply.
9. Use the Collection tab to browse hairstyle images grouped by year.
10. Open the Location page to view salon branch details, contact information, and opening hours.
11. Use the Profile tab to update your personal details.

### Booking Flow

1. Choose services from the Services tab.
2. Select the role or stylist level if shown.
3. Add multiple services if needed.
4. Submit the booking.
5. A new conversation will be created automatically in the Messages tab.
6. The booking request will include the guest name and selected services.
7. Admins can then reply inside that conversation thread.

### Collection Flow

1. Open the Collection tab.
2. Select a year bundle such as `2021` or `2022`.
3. View all collection images from that year.
4. Use the back action to return to the year list.

### Messages Flow

1. Open the Messages tab to see all conversations.
2. Tap a conversation to open its full thread.
3. Send follow-up questions or booking details in that conversation.
4. Return to the conversation list to view other booking threads.
